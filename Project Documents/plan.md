# One more thing...

I'd like to make one improvement to our mentorship.

I want every Sprint to start like a real Agile sprint.

For example:

---

## Sprint Goal

Today we want to understand:

> **What is Express and why do we need it?**

---

## Success Criteria

By the end of today you should be able to answer:

* What is Express?
* Why not use Node alone?
* What does `app.listen()` do?
* What is a route?
* What happens when the browser sends `GET /`?

If you can't explain those things, we don't move on.

---

## Sprint Review

At the end of every session we'll ask:

* What did we build?
* What did we learn?
* What still feels confusing?
* What would QA test?

That mirrors how many Agile teams work and helps reinforce the concepts.
