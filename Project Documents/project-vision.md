# Moonlight Ballroom Gallery

## Purpose

The Moonlight Ballroom Gallery is a web application designed to showcase
student performances, events, and memories from the dance studio.

The goal is not only to display photos, but to create an emotional connection
with visitors and show that ballroom dancing is welcoming, fun, and achievable
for everyone.

---

## Users

### Visitors
They should be able to:
- Explore dance performances
- Browse albums
- View photos
- Understand the atmosphere of the studio

### Students and Families
They should be able to:
- Find memories from events
- View performance photos

### Administrator
They should be able to:
- Create albums
- Upload photos
- Organize content
- Manage visibility


## Version 1 Goals

The first version should be:

- Simple
- Stable
- Easy to use
- Easy to maintain
- Ready to grow later

Features:

- Album listing
- Album details
- Photo gallery
- Featured albums/photos
- Basic photo management
