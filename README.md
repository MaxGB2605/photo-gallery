# Photo Gallery

A full-stack photo gallery application built as a learning project.

## Tech Stack

- Frontend: HTML, CSS, JavaScript
- Backend: Node.js, Express
- Database: SQLite

## Current Features

- Express server
- Static frontend
- SQLite database
- GET /albums
- POST /albums

## Project Goals

- Learn full-stack JavaScript
- Learn REST APIs
- Learn database design
- Apply QA engineering practices
